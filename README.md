# WordFlip

Минималистичные флеш-карточки для английских и русских слов. Без сборки, фреймворков и бэкенда: три файла, браузер и `localStorage`.

- Добавление слов с автоматическим определением языка
- Поиск по словам и переводам, включая неточные совпадения
- Импорт из буфера обмена и JSON, экспорт в JSON
- Перемешивание колоды
- Озвучивание английских слов через Puter.js — без ключей и настройки API
- Отдельный режим «Повторение» с очередью и прогрессом
- Вкладка «Расписание»: интервальные повторения с очередью на день и лимитом 300 слов
- Итоги сессии: сколько слов отвечено с первого раза, со списком этих слов
- Светлая, тёмная и системная темы
- Необязательная синхронизация через секретный GitHub Gist
- Клавиатурная навигация и адаптивная вёрстка

## Быстрый старт

### Локально

Скачайте или склонируйте репозиторий и откройте `index.html` в браузере.

Для полного доступа к буферу обмена и синхронизации удобнее запустить локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000).

Сборка не нужна: приложение состоит из статических файлов.

### GitHub Pages

1. Загрузите файлы в репозиторий на GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`.
5. Сохраните настройки и дождитесь публикации.

После публикации приложение будет доступно по адресу вида `https://username.github.io/repository/`.

> Для чтения буфера обмена и синхронизации с GitHub нужен `https://` или `localhost`. На GitHub Pages HTTPS включён по умолчанию.

## Как пользоваться

### Карточки

- Введите слово и перевод в форму «Добавить слово». Язык первого поля определяется автоматически: кириллица сохраняется в русское поле, латиница — в английское.
- Нажмите на карточку, чтобы перевернуть её и увидеть перевод. Повторное нажатие скрывает перевод.
- Наведите курсор на карточку и нажмите `×`, чтобы удалить слово.
- Переключатель **English / Русский** в шапке задаёт, какая сторона показывается первой.
- Кнопка **Перемешать** случайно переставляет текущую колоду.
- Кнопка **🔊** рядом с английским словом произносит его.
- Поиск ищет по обоим языкам и допускает неточные совпадения.

### Произношение

Английские слова озвучиваются через [Puter.js](https://docs.puter.com/AI/txt2speech/) — бесплатный TTS без ключей и регистрации приложения. Скрипт `https://js.puter.com/v2/` подключается в `index.html`, а звук запрашивается через `puter.ai.txt2speech()`.

- Кнопка **🔊** показывается рядом с английским словом на карточках, в «Повторении» и в «Расписании» — с той стороны, где виден английский текст.
- Используется голос `Joanna` (движок `neural`, язык `en-US`), поэтому английские слова читаются именно английским голосом, а не системным русским.
- Скорость воспроизведения — `0.9`.
- Перед новой озвучкой предыдущая останавливается, а на кнопке на время запроса появляется индикация загрузки. Если нажать другое слово, устаревший ответ не проигрывается.
- Автоматически ничего не произносится: только по клику или по `Enter`/`Space` на кнопке. Карточка при этом не переворачивается.
- Для синтеза нужен интернет: выбранное слово отправляется в Puter. Puter работает по модели «платит пользователь», поэтому при первом нажатии откроется окно входа в аккаунт Puter (например, через Google). Вход нужен один раз — дальше браузер помнит сессию.
- Если окно входа закрыть, озвучка продолжит работать системным английским голосом, а попап больше не будет открываться до перезагрузки страницы.
- Запрос к Puter ограничен 12 секундами: если сервис не ответил, кнопка перестаёт показывать загрузку и включается запасной вариант — системный английский голос (`en-US` → `en-GB` → любой `en`). Если английского голоса нет, выводится сообщение и список доступных голосов в консоли.
- Озвучка работает на GitHub Pages: доступ к микрофону не нужен, HTTPS уже включён. Окно входа Puter требует `https` или `localhost`; при открытии файла прямо с диска (`file://`) озвучка сразу идёт системным голосом.
- В подвале страницы стоит ссылка **Powered by Puter** — этого требует Puter.js.

### Повторение

Вкладка **Повторение** запускает сессию по всей колоде. Карточки каждый раз перемешиваются заново.

1. Сначала видно только слово на выбранном языке.
2. Нажмите на карточку, чтобы увидеть перевод.
3. Оцените себя:
   - **✓ Знаю** — карточка помечается выученной и уходит в конец очереди;
   - **✕ Не знаю** — карточка остаётся невыученной и возвращается дальше по очереди.
4. Счётчик показывает **«Выучено: X из Y»**, а полоса сверху — прогресс.
5. Когда выучены все слова, появляется экран **«Все слова повторены!»**.
6. **Перезапуск** доступен в любой момент: он сбрасывает прогресс и заново перемешивает колоду.

Как работает возврат после **✕**:

- карточка вставляется в случайную позицию с 10-й по 30-ю (индексы 9–29);
- если невыученных карточек осталось меньше, позиция выбирается в пределах оставшихся невыученных;
- карточка никогда не попадает после первой выученной карточки;
- если невыученных больше нет, карточка возвращается в начало очереди.

Статус «выучено» действует только в текущей сессии. Он не сохраняется в слова и не синхронизируется.

### Итоги сессии

Когда все карточки выучены, на экране завершения появляется сводка **«С первого раза»**: слова, которые при самом первом показе в этой сессии были отмечены как **✓ Знаю**. Если слово сначала отметили как **✕ Не знаю**, а потом выучили, в эту сводку оно уже не попадает.

Слова показываются в виде чипов `english — russian` и переносятся на несколько строк. Сводка относится только к текущей сессии: кнопка **Перезапуск** очищает её и начинает колоду заново, между перезагрузками страницы она не сохраняется и с GitHub Gist не синхронизируется.

### Расписание

Вкладка **Расписание** — отдельный режим интервальных повторений. У него собственный список слов и собственный прогресс: действия здесь не меняют колоду «Карточек» и сессию «Повторения».

Слова попадают в расписание автоматически при любом добавлении в «Карточках»: вручную, из буфера обмена, из JSON-файла и при загрузке из GitHub Gist. Если такое слово в расписании уже есть, остаётся более старое. Совпадением считается точное сочетание букв слова и перевода без учёта регистра, поэтому `ice cream` и `icecream` — разные слова.

Удаление слова из «Карточек» **не** удаляет его из расписания: для этого есть список **Слова** внутри вкладки. Там же можно добавлять слова вручную и искать по ним.

Интервалы отсчитываются в днях от момента ответа:

| Ступень | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Дней до повтора | 0 | 1 | 2 | 4 | 7 | 14 | 30 | 60 | 180 |

- **✓ Знаю** — слово переходит на следующую ступень. На ступени 8 каждый правильный ответ оставляет интервал 180 дней.
- **✕ Не знаю** — интервал делится вдвое с округлением вниз (`14 → 7`, `7 → 3`, `1 → 0`), а ступень уменьшается на одну. Минимальный интервал — 0 дней: слово возвращается в конец очереди на сегодня.
- Просроченные слова не теряются: всё, у чего дата повтора наступила или прошла, суммируется в очереди на сегодня и показывается от самых старых.
- Лимит — **300 слов в день**. Если накопилось больше, лишние переносятся на следующие дни с учётом уже занятых дней.
- Полоса сверху показывает **«Сегодня: X из Y»** и сколько слов осталось.

Очередь на день сохраняется в браузере: можно закрыть страницу и продолжить позже. При наступлении новых суток план строится заново.

## Импорт и экспорт

### Импорт из буфера обмена

Откройте **Импорт из буфера**, вставьте список — по одному слову в строке. Перевод можно указать сразу, отделив его одним из разделителей:

```text
apple — яблоко
journey: путешествие
butterfly	бабочка
knowledge = знание
friend; друг
window, окно
```

Также поддерживаются маркеры списка (`-`, `*`, `•`, `1.`) — они будут убраны.

Если перевод не указан, приложение предложит заполнить его на следующем шаге. Дубликаты и уже существующие слова пропускаются: если в словаре уже есть `say` с другим переводом, строка `say — говорить` тоже будет пропущена. В сообщении после разбора показывается, сколько строк пропущено и почему (`уже есть в словаре`, `повторяются в списке`, `не распознаны`).

### JSON

Кнопка **Экспорт** скачивает файл с колодой и расписанием. **Импорт JSON** добавляет новые слова, пропуская совпадения, и обновляет прогресс расписания.

Формат экспорта:

```json
{
  "app": "WordFlip",
  "version": 2,
  "exportedAt": "2026-11-15T10:00:00.000Z",
  "words": [
    { "id": "optional-id", "english": "apple", "russian": "яблоко" }
  ],
  "schedule": [
    {
      "id": "schedule-id",
      "english": "apple",
      "russian": "яблоко",
      "step": 2,
      "interval": 2,
      "dueDate": "2026-11-17",
      "addedAt": 1763200000000,
      "updatedAt": 1763200000000,
      "lastReviewedOn": "2026-11-15",
      "lastResult": "known"
    }
  ]
}
```

- `words` — колода «Карточек»;
- `schedule` — независимый список расписания со ступенью, интервалом и датой следующего повтора.

Поле `id` необязательно — при отсутствии оно будет создано автоматически. Импорт понимает и старый формат: массив слов или объект с массивом в поле `words`. Если в файле нет `schedule`, расписание просто пополнится новыми словами; если есть — прогресс объединяется по словам, приоритет у более свежей записи, а при совпадении остаётся более старое слово.

## Синхронизация с GitHub Gist

Приложение умеет хранить слова в **секретном gist** вашего GitHub-аккаунта. Это позволяет открывать одну и ту же колоду на разных устройствах.

В файле gist хранятся обе части данных: колода (`words`) и расписание (`schedule`) с прогрессом повторений. Поэтому синхронизация не сбрасывает ступени и даты следующих повторов.

### На первом устройстве

1. Создайте [personal access token](https://github.com/settings/tokens/new?scopes=gist&description=WordFlip) с областью доступа `gist`.
2. Откройте диалог синхронизации (кнопка с облаком в шапке).
3. Вставьте токен.
4. Нажмите **Создать новый gist**.

### На другом устройстве

1. Вставьте тот же токен.
2. Укажите ID gist или ссылку на него.
3. Нажмите **Скачать с GitHub**.

После этого синхронизация включается автоматически: изменения отправляются примерно через 1,6 секунды, а также выполняются проверки при загрузке страницы, возвращении на вкладку и восстановлении соединения.

Доступны и ручные действия:

- **Скачать с GitHub** — заменить локальные слова данными из gist;
- **Загрузить на GitHub** — заменить содержимое gist локальными словами;
- **Отключить** — выключить синхронизацию и удалить токен из браузера.

### Важно о безопасности

- Токен хранится только в `localStorage` вашего браузера и отправляется только на `api.github.com`.
- Используйте отдельный токен только с областью `gist` и не применяйте его на общем компьютере.
- Gist с пометкой «secret» не отображается в поиске, но доступен любому, у кого есть ссылка. Не храните там конфиденциальные данные.
- При одновременном редактировании на двух устройствах побеждает последняя сохранённая версия.

## Данные и приватность

Приложение не использует аналитику, не отправляет данные на сторонние серверы и не требует аккаунта. Всё хранится в браузере.

| Ключ | Назначение |
| --- | --- |
| `wordflip.words.v1` | Слова и порядок колоды |
| `wordflip.settings.v1` | Язык карточек и тема |
| `wordflip.meta.v1` | Время последнего изменения |
| `wordflip.sync.v1` | Токен и ID gist |
| `wordflip.schedule.v1` | Слова расписания, их ступени и очередь на день |

При первом запуске загружается небольшая демонстрационная колода. Очистка данных сайта удаляет слова, настройки и токен — заранее сделайте экспорт JSON или сохраните данные в gist.

`localStorage` привязан к источнику: `file://`, `http://localhost` и GitHub Pages используют разные хранилища.

## Клавиатура и доступность

- `Enter` или `Space` на карточке — перевернуть её.
- `Enter` или `Space` на кнопке **🔊** — произнести английское слово.
- `Tab` / `Shift+Tab` — перейти к кнопкам и другим элементам.
- Стрелки `←` / `→`, `Home` / `End` — переключение между вкладками.
- У интерактивных элементов есть подписи для скринридеров и видимый фокус.
- Поддерживается `prefers-reduced-motion`: анимации отключаются при соответствующей системной настройке.

## Ограничения

- Нет серверной части и аккаунтов: данные живут в конкретном браузере.
- Очередь «Повторения» и итоги «С первого раза» не сохраняются между перезагрузками страницы: это состояние текущей сессии.
- Очередь расписания на день сохраняется, но привязана к текущей дате: с наступлением новых суток план строится заново.
- Колода синхронизируется по принципу last-write-wins, а расписание объединяется по словам: берётся более свежий прогресс и более старое слово.
- Приложение не является PWA и не кэширует себя для офлайн-запуска с GitHub Pages; локальная копия работает без интернета.
