Синхронизация с GitHub

Бесплатно, через секретный Gist

GitHub Pages — статический хостинг, поэтому слова не могут храниться на нём напрямую. Зато приложение умеет сохранять их в секретный gist вашего GitHub-аккаунта. Это бесплатно и работает на любом устройстве.

  1. Создайте personal access token с галочкой gist.
  2. Вставьте токен ниже. Нажмите «Создать новый gist» на первом устройстве.
  3. На другом устройстве вставьте токен и ID gist, затем нажмите «Скачать с GitHub».

Токен хранится только в localStorage этого браузера и отправляется только на api.github.com. Не используйте общий компьютер. При одновременном редактировании на двух устройствах побеждает последняя сохранённая версия.
